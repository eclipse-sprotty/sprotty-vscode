# States example

This folder contains an example VS Code extension with a [Langium](https://langium.org)-based language server and a Sprotty diagram for a simple domain-specific language for statemachines.

## Build

Run in the repository root:

```bash
yarn
```

## Run

Press F5 in VS Code (launch configurations in `.vscode/launch.json` at the repository root) and open a `.sm` file from `examples/workspace`. See `../AGENTS.md` for the build details and traps.
